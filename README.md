# RTL_Design_and_Synthesis_Workshop
RTL Workshop is a hands-on learning series. It covers a complete flow, from RTL to GDS. The content for this workshop is structured by lectures, practical labs,  explanatory code.

  ## About This Workshop

This workshop is includes :

,Verilog RTL design and synthesis
 ,Icarus Verilog and GTKWave for simulation and waveform analysis
 ,Yosys and SKY130 open-source PDK for logic synthesis
 ,Testbenches, timing libraries, D flip-flop coding styles and optimization

---

## Prerequisites

- Basic understanding of digital logic (gates, flip-flops, multiplexers, etc.)
- Familiarity with Linux shell commands
- A Linux environment
- Tools: git, Iverilog, GTKwave, Yosys, and a text editor

 --

 ## Workshop Structure

This workshop consists of following.

- [Day 1 – Introduction to Verilog](./Day1_Introduction_to_Verilog/)

- [Day 2 – Simulation with Icarus Verilog](./Day2_Simulation_with_Icarus_Verilog/)

- [Day 3 – Logic Synthesis with Yosys](./Day3_Logic_Synthesis_with_Yosys/)

- [Day 4 – GLS, Blocking and Non-blocking in Verilog, Synthesis](./Day4_GLS_Blocking_NonBlocking_Synthesis/)

- [Day 5 – Optimization Techniques](./Day5_Optimization_Techniques/)
 
Each day's folder includes:
- A README.md explaining the day's concepts
- Practical lab exercises
- Verilog code examples
